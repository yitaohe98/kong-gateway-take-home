# Kong Gateway Take-Home Assignment

Preparation and implementation workspace for the Kong Gateway Engineer interview.

## Assignment

The assignment offers three independent options. We will evaluate them first and
implement one of them:

1. Distributed cluster rate-limiting plugin
2. HTTP idempotency middleware plugin
3. Reliable asynchronous webhook delivery system

## Context

The design should be grounded in Kong Gateway's request path and plugin model,
with attention to distributed systems, Linux/networking behavior, failure modes,
performance, observability, and production readiness.

## Repository status

This repository is intentionally initialized as a clean workspace. The selected
assignment and implementation plan will be added after comparing the three options.
